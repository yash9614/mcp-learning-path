# 05 — LangChain MCP Adapters

## Core Concepts

The **LangChain MCP Adapters** let you use MCP tools as regular LangChain tools. This means you can plug MCP servers into LangChain chains or LangGraph agents with very little extra code.

This is the bridge between the Agentic AI world and MCP.
