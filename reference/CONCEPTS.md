# Concept Glossary — MCP

| Term | Meaning |
|------|---------|
| **MCP** | Model Context Protocol — open standard for connecting AI apps to tools and data |
| **Server** | Process that exposes tools, resources, and prompts |
| **Client** | Process that connects to servers and calls tools (often an agent or IDE) |
| **Tool** | Callable function exposed by a server |
| **Resource** | Readable data exposed by a server |
| **Prompt** | Reusable prompt template exposed by a server |
| **stdio** | Standard input/output transport (local process) |
| **SSE** | Server-Sent Events transport (HTTP) |
| **Streamable HTTP** | Newer HTTP transport for MCP |
| **Adapter** | Library that turns MCP tools into LangChain tools |
| **Multi-server client** | Client that aggregates tools from several MCP servers |

Cross-reference the module READMEs for deeper explanations.
