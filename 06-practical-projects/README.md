# 06 — Practical Projects

## AgentWriter-AI

A full blog generation agent with:
- Notebooks showing progressive complexity (basic → research → image gen)
- A web app (Flask-style) frontend + backend

**Location in dump:** `AgentWriter-AI/`

**Why it matters:** Shows how to turn agent logic into a usable application.

## Clinisight

Domain-specific MCP tools for medical/symptom related tasks (PubMed search, symptom extraction, summarization, etc.).

**Location in dump:** `Clinisight/`

**Why it matters:** Demonstrates building specialized tools and exposing them via MCP.

## Interview Questions

1. How would you turn a multi-step agent into a web application?
2. What domain-specific tools would you expose via MCP for a healthcare use case?
3. How do you handle external API keys and rate limits inside MCP tools?
